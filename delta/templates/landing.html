02 / The handoff

Previous work is a candidate.
Not a permission slip.

Delta reads declared inputs, dependencies, freshness, implementation identity, and exposure policy. It makes the call before prompt construction.

REUSE

Approved work crosses.

Its signatures and policy still match the receiving agent.

BLOCKED

Private work stops.

It remains in Sibyl and never enters Agent B's context.

RERUN

Changed work runs again.

Only missing work moves toward a new execution.
